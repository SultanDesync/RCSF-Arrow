# Royal Canadian Space Force: Avro Arrow

A flyable Avro Arrow starfighter and Royal Canadian Space Force uniforms for Starfield. No script extender needed.

- Landing gear that folds into sealed wells
- Guns that swing out of the nose when powered
- A belly missile rack behind bomb-bay doors
- Retro thrusters beside the canopy

**[Download the latest build](https://github.com/SultanDesync/RCSF-Arrow/releases)**

This repository holds downloads only. The mod is in early alpha, so back up your saves.

Found a bug? Post in #sf-support on the [Discord](https://discord.gg/jjk8nEMzFK) with the **RCSF Arrow** tag, or open an issue here.
